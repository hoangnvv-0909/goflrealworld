## 3. What to do, in this order

1. Reproduce the crash with the command(s) above.
2. Locate the root cause. Before you change any code, write `gofl-localize.json` in the project root:

   ```json
   {"locations": [{"file": "path/relative/to/root.go", "function": "Type.Method", "line": 0}], "explanation": "..."}
   ```

   List the places to fix, most important first.
3. Fix the root cause. Do not only add a nil check, a bounds check or a recover at the crash point if the fault is elsewhere.
4. Run the reproduce command(s) again: they must no longer crash. Every other test of the project must still pass.
